## Key features

- UI Builder: Make cool custom menus
- Events: Run commands when something happens in the world
- Moderation: Punish players for breaking the rules
- Combat Log: Prevent players from leaving when they're in combat
- Clans: Allow players to team up, create a base they can tp to, and contribute money to a bank
- Player Shop: Players can sell items, buy items from other people, and search shops
- Binding: Bind commands to entities and items

## Install Feather Essentials

Prepackaged versions of Feather Essentials are available on https://curseforge.com/minecraft-bedrock/scripts/feather
You can package the Behavior Pack yourself using this repository. You can get the Resource Pack from the CurseForge link.
